### EnrichAnything public API
---

EnrichAnything publishes read-only JSON for public market scans and short report summaries.

Use it when you want sample structured data for:

- ecommerce channel-gap lists
- GTM hiring signals
- operator-friendly reports you can plug into internal workflows

Start here:

- [Homepage](https://www.enrichanything.com/)
- [API docs](https://www.enrichanything.com/api/)
- [OpenAPI spec](https://www.enrichanything.com/openapi.json)

### Included requests
---

1. **Get public market**

   Returns one published market scan by slug.

2. **Get public report**

   Returns one published report summary by slug.

3. **Get OpenAPI spec**

   Returns the public OpenAPI file for the API surface.
